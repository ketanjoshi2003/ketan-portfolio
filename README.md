# Ketan Joshi — Portfolio

Personal portfolio website for **Ketan Joshi**, a backend-focused full-stack engineer based in Mehsana, Gujarat, India.

## Live site

**https://ketanjoshi2003.github.io/ketan-portfolio/**

## Tech

- Single-file static site — pure HTML, CSS, vanilla JavaScript
- Editorial design with Fraunces / Instrument Sans / JetBrains Mono
- IntersectionObserver-based reveal animations (respects `prefers-reduced-motion`)
- Fully responsive, no frameworks, no build step

## Sections

1. **About** — background, ownership philosophy, key facts
2. **Skills** — languages, frameworks, databases, tools
3. **Experience** — COMS2 Conference rebuild (Apr–May 2026)
4. **Work** — PromptOps, DRR (Digital Reading Room), Synapse
5. **Education** — MCA (2026) & BCA (2024), Ganpat University
6. **Contact** — email, LinkedIn, GitHub

## Deploy

Hosted on **GitHub Pages** (legacy build, served from `/main` root).
